# /sdd:status

## O que faz

Mostra onde o projeto está no SDD (feature ativa, fase, nível, artefatos
existentes, progresso das tarefas e lacunas de rastreabilidade) e recomenda um
único próximo comando. Não altera nada.

## Quando usar

Você digita `/sdd:status`; o agente não a usa por conta própria. Use ao voltar
a um projeto, ao trocar de máquina ou sempre que perder o fio. O mesmo painel
sai no terminal com `sdd-status`.

## Está funcionando se

- A fase atual aparece destacada no ciclo.
- A "próxima" tarefa bate com a primeira tarefa aberta de `tarefas.md`.
- A recomendação é um comando só.

## Onde se encaixa

Uso avulso, a qualquer momento. Para "qual comando serve para esta situação",
use a [ajuda](ajuda.md), que é o mapa completo.
